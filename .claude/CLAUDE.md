# dotfiles-desktop

## Comments

This repository documents its reasoning in comments, and that overrides the
global "no comments unless requested" rule. Every non-obvious setting, script
and QML file carries a short note saying why it is the way it is, not what it
does. New code here follows the same convention.

The reason is the reinstall this repository exists for: these files will be
read on a bare system by someone with no memory of the decisions behind them.
A `kb_variant`, a disabled scan-out path or an unreachable idle listener is
indistinguishable from a mistake without the sentence explaining it.

Keep the notes to the rationale. Do not narrate what the code plainly says.
